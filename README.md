# House Pricing Prediction
This project has not been made to be used in production. It is a simple project to predict house prices using machine learning algorithms.
It is only for educational purposes.

Dataset: By me
Pre Processing: Just a normalization of the data and a split between train and test data.
Architecture: A simple neural network with 3 hidden layers and ReLU activation function.
Training Method: Supervised training with MSE loss function and Adam optimizer.
Used metrics: mainly MSE
Limits: *This model is not trained to be used in production. It is a simple project to predict houses prices using Machine Learning algorithms. It is only for educational purposes.*
